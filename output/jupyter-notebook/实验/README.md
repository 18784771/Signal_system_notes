# 信号与系统实验

推荐 Python **3.13**（本次验证 3.13.9）；支持范围 **>=3.12,<3.14**，其他版本未验证。全部实验代码在 `.ipynb` 内，不依赖外部数据或辅助 Python 模块。

## 安装和启动

在本目录打开终端：

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Linux / macOS / WSL
# source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyter lab
```

也可用 `uv venv --python 3.13` 创建环境，再用 `uv pip install -r requirements.txt` 安装。Jupyter 中选择对应虚拟环境的 Python 内核；若已有其他内核，使用 `python -m ipykernel install --user --name signals-lab --display-name "信号系统实验"` 注册。

## 学习顺序

1. [卷积](01_卷积.ipynb)：冲激分解、翻转平移、连续近似、回声与平滑。
2. [系统的性质](02_系统的性质.ipynb)：线性、时不变、记忆、因果、稳定、连接、可逆。
3. [微分与差分方程](03_微分与差分方程.ipynb)：初值、自然与受迫响应、特征根、递推、温度平滑。
4. [傅里叶](04_傅里叶.ipynb)：级数、变换、全部笔记性质、DFT/FFT、频域滤波。

每个 notebook 独立准备环境，选择“重启内核并运行全部”即可。每节先读公式并预测结果，运行后对照“观察与应用”，再改参数。原笔记在仓库根目录；重复讲解的性质合并为一个实验。图用英文标签避免中文字体依赖，正文与结果说明为中文。

## 数值约定

连续傅里叶采用角频率 omega（rad/s），逆变换系数 1/(2pi)。FFT 使用 NumPy 的离散约定；Hz 频率用 fftfreq 的采样间隔转换。连续积分是有限区间、有限步长近似；离散冲激幅度为 1，连续冲激用面积为 1 的窄脉冲近似。实验中出现的零填充、边界、初值和稳态条件均在对应节说明。有限样本反例可以否定一种系统性质，少量成功案例不能代替一般证明。
